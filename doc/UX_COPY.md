# Podcast Studio UX 文案体系

> 版本: 1.0 | 更新日期: 2026-10-13
> 适用范围：全站按钮、提示、空状态、错误信息。与 `doc/UX_DESIGN.md` 的反馈层级配套使用。

---

## 一、语气与人格

**系统人格**：一个利落的工作室助手——专业、直接、有温度，像坐在你旁边的剪辑师。

**四条规则**：

1. **说人话**：不裸露技术术语。不出现"409 冲突""500 错误""API 返回异常"这类字眼；技术细节收进括号或"详情"折叠区
2. **说结果**：告诉用户"发生了什么 + 接下来能做什么"，不只报告失败
3. **第二人称**：用"你"，不用"用户"，不用"请稍候"（直接说在做什么）
4. **不装可爱**：不用emoji堆砌、不用"啦/哦/捏"；可用克制的口语词（"先""再""搞定"）

**对比示例**：

| ❌ 避免 | ✅ 采用 |
|---|---|
| 操作成功！ | 已保存 |
| 请求失败：HTTP 500 | 生成失败了，点下方按钮重试 |
| 数据加载中... | 正在读取节目列表… |
| 确定要删除吗？ | 删除后不可恢复。确定删除「科技双响炮 · 10月14日」？ |

## 二、按钮文案规范

- **动词开头，2–4 字**，不戴"请"字帽
- 进行时在动词后加"…中"：生成 → 生成中…
- 主按钮文案必须说出动作对象，不用孤零零的"确定/提交"

| 场景 | 文案 | 进行中 |
|---|---|---|
| 逐字稿 | 生成逐字稿 / 重新生成 | 生成中…（约 30 秒） |
| 音频 | 生成音频 / 重新生成 | 合成中… |
| 发布 | 标记发布 | — |
| 新闻入库 | 加入节目（N） | — |
| 抓取 | 抓取新闻 / 抓取最新 | 抓取中… |
| 保存 | 保存 / 保存并验证（API key） | 保存中… |
| 删除确认 | 取消 / 删除（红） | — |
| 失败恢复 | 重试 | — |
| 标题建议 | 换一批 / 忽略 | AI 正在构思标题… |
| 题图 | 生成题图 / 换一批 / 下载 PNG | AI 正在构思画面… |
| 音频导出 | 导出音频 | 导出中… |
| 图文正文 | 生成图文正文 / 复制 Markdown / 下载 PNG | 正在提炼素材要点… / 正在撰写正文… |

## 三、场景文案库

### 3.1 空状态（图标 + 一句话 + 一个动作）

| 场景 | 文案 | 动作按钮 |
|---|---|---|
| 首次进入（未配置） | 三步开始你的第一期节目：配置 API → 添加新闻源 → 抓取新闻 | 去配置 |
| 无节目 | 今天还没有节目，现在开始一期？ | 开始今日节目 |
| 节目内无新闻 | 先在右侧点选新闻，AI 才能开始写稿 | 添加新闻 |
| 新闻池为空 | 新闻池还是空的，先抓一批看看 | 抓取新闻 |
| 筛选无结果 | 没有符合条件的新闻，试试降低评分门槛 | 清除筛选 |
| 无逐字稿 | 还没有逐字稿 | 生成逐字稿 |
| 无音频 | 逐字稿就绪后，在这里合成音频 | —（置灰） |

### 3.2 进度文案（音频生成各阶段）

| stage | 展示文案 |
|---|---|
| starting | 正在准备… |
| parsing | 正在解析逐字稿… |
| submitting | 正在提交配音任务（N 段）… |
| processing | 配音生成中…（这个步骤最久，可以离开页面） |
| downloading | 正在下载音频片段… |
| merging | 正在合并成完整节目… |
| done | 搞定，可以试听了 🎧 |
| error | 合成失败：{原因} |

逐字稿生成（无分段进度时）：`正在阅读素材并撰写对话，约需 30 秒，你可以先整理左侧的新闻列表`

### 3.3 Toast 文案

| 场景 | 文案 |
|---|---|
| 保存成功 | 已保存 |
| 抓取完成 | 已抓取 N 条新闻，已自动评分 |
| 加入节目 | 已加入「节目名」（N 条） |
| 选料点选加入 | 已加入 |
| 软删除新闻 | 已移除该新闻 [撤销] |
| 标题建议采纳 | 已更新标题 |
| 题图生成完成 | 题图已生成，挑一版喜欢的 |
| 题图选定 | 已选为本期题图 |
| 题图下载 | 已开始下载（2x PNG） |
| 音频导出 | 已开始下载 |
| 正文生成完成 | 图文正文已生成，共 X 字 |
| 正文复制 | 已复制 Markdown |
| 正文长图下载 | 已开始下载（1.5x PNG 长图） |
| 逐字稿生成完成 | 逐字稿已生成，共 X 字 |
| 音频合成完成 | 音频已生成，可以试听了 |
| 标记发布 | 已发布 🎉 |
| 网络异常 | 网络异常——请确认后端服务正在运行，然后重试 |
| 保存失败 | 保存失败：{原因}。你的内容还在编辑框里，不会丢失 |

### 3.4 确认弹窗（破坏性操作）

| 操作 | 标题 | 正文 | 按钮 |
|---|---|---|---|
| 删除节目 | 删除这期节目？ | 「标题」及其逐字稿、音频将被永久删除，不可恢复。 | 取消 / 删除 |
| 删除音频 | 删除已生成的音频？ | 逐字稿会保留，删除后可以重新合成。 | 取消 / 删除 |
| 覆盖逐字稿 | 重新生成会覆盖现有逐字稿 | 你对逐字稿的手动修改将丢失。建议先复制保存需要保留的段落。 | 取消 / 覆盖并生成 |
| 移除新闻 | 从节目中移除这条新闻？ | 只从本期节目移除，新闻池里仍然保留。 | 取消 / 移除 |

### 3.5 错误文案（页面内错误卡）

| 场景 | 文案 |
|---|---|
| 逐字稿生成失败 | 生成失败：{DeepSeek 连接失败 / 内容过长 / 其他原因}。素材和备注都还在，点击重试。 |
| 音频合成失败 | 合成失败，停在「{阶段}」。已生成的片段会保留，重试不会重复扣费。 |
| API Key 无效 | {DeepSeek / MiniMax} 的 Key 无效或未配置，请到 设置 → API 配置 检查。 |
| Key 需重启生效 | DeepSeek 的 Key 已保存，重启后端后生效；MiniMax 的 Key 即时生效。 |

### 3.6 格式规范

- **时间**：今天显示"今天 HH:mm"，当年显示"M月D日"，跨年显示"YYYY年M月D日"；列表里避免完整 ISO 时间戳
- **字数**：中文计字，"约 4,200 字 · 预计 28 分钟"（150 字/分钟换算，向上取整）
- **评分**：星级 + 具体分并示，如 `★★★★☆ 82`
- **数字**：千分位逗号；百分比取整

## 四、角色口吻附录（播客内容内，非系统 UI）

系统 UI 文案遵守上述规范；播客**节目内容**里两个角色的口吻由 `prompts.yaml` 定义（彪悍罗犀利、OK王专业），与 UI 文案是两套语料，不要混用——UI 里不出现角色口吻，节目稿里不出现系统提示语。
